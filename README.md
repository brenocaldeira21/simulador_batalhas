# simulador_batalhas
## for vs while - qual a diferença?
O for repete uma sequência conhecída ("faça X vezes" ou "percorra essa lista").
O While repete enquanto uma condição for verdadeira, sem saber quantas vezes.
## Para que serve o return?
Sem o return o calculo fica preso dentro da função e some.
Serve para ter aquele dado guardado diferente de usar print
O resultado é armazenado e reutilizado.
## O que é loop infinito? como evitar?
É quando a condição de while nunca vira falsa e o programa fica rodando pra sempre. 
Evitamos garantindo que algo dentro do loop modifique a condição. 
O Hp vai diminuindo a cada turno até chegar a zero, encerrando loop.
